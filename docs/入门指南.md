# AI-QA 入门指南

**更新时间**: 2026-03-24

## 项目简介

AI-QA 是一个面向企业知识问答场景的 AI 应用，支持：

- 普通 AI 对话
- RAG 知识库问答
- 多知识库管理
- 历史会话管理
- 文档上传、预览、删除
- 用户登录鉴权
- 对外开放的知识库文档上传接口

当前技术栈：

| 分类 | 技术 |
| --- | --- |
| 后端 | Spring Boot 3.4.2 |
| AI | Spring AI 1.0.0-M5 |
| 模型 | 通义千问兼容 OpenAI 接口 |
| 数据库 | PostgreSQL + pgvector |
| 缓存 | Redis |
| ORM | MyBatis-Plus |
| 鉴权 | Sa-Token |
| 前端 | Vue 3 + Vite + Element Plus |

## 运行环境

- Java 17
- Maven 3.9+
- PostgreSQL
- Redis
- Node.js 18+
- `QWEN_API_KEY` 环境变量

## 关键配置

后端配置文件在 [application.properties](/D:/workspace/包装项目/Ai-QA/src/main/resources/application.properties)。

当前默认端口：

- 后端：`7000`
- 前端开发：`3000`
- PostgreSQL：`5432`
- Redis：`6379`

启动前至少确认这些配置可用：

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/susan_ai
spring.datasource.username=postgres
spring.datasource.password=123456
spring.data.redis.host=localhost
spring.data.redis.port=6379
spring.data.redis.password=${REDIS_PASSWORD:123456}
spring.ai.openai.api-key=${QWEN_API_KEY}
```

## 启动步骤

### 1. 启动 PostgreSQL 和 Redis

如果你用本机服务，先确认 PostgreSQL 和 Redis 已启动。  
如果你用 Docker，再按你的本地环境启动对应容器。

### 2. 设置环境变量

```powershell
$env:QWEN_API_KEY="你的千问 API Key"
$env:JAVA_HOME="D:\Javasource\jdk-17.0.9"
$env:PATH="$env:JAVA_HOME\bin;D:\Javasource\apache-maven-3.9.2\bin;$env:PATH"
```

如果你的 Redis 密码不是 `123456`，再额外设置：

```powershell
$env:REDIS_PASSWORD="你的 Redis 密码"
```

### 3. 启动后端

```powershell
mvn spring-boot:run
```

### 4. 启动前端

```powershell
cd ui
npm install
npm run dev
```

## 访问入口

- 前端工作台：`http://localhost:3000`
- 后端服务：`http://localhost:7000`

首次访问会进入登录页，支持邮箱或手机号注册登录。

## 常用接口

### 用户与登录

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `GET /api/auth/session`

### 会话

- `GET /ai/conversations`
- `POST /ai/conversations`
- `GET /ai/conversations/{id}/messages`
- `PUT /ai/conversations/{id}/title`
- `DELETE /ai/conversations/{id}`

### 知识库

- `GET /api/knowledge-bases`
- `POST /api/knowledge-bases`
- `PUT /api/knowledge-bases/{id}`
- `DELETE /api/knowledge-bases/{id}`
- `GET /api/knowledge-bases/{id}/documents`

### 文档

- `POST /ai/upload`
- `GET /ai/documents`
- `GET /ai/documents/{id}/preview`
- `DELETE /ai/documents/{id}`

### 开放接口

- `POST /api/open-api-tokens`
- `GET /api/open-api-tokens`
- `DELETE /api/open-api-tokens/{id}`
- `POST /openapi/knowledge-bases/{kbId}/documents`

## 开放上传接口示例

先在系统内登录后创建一个开放 token，然后外部项目可以这样上传文档：

```bash
curl -X POST "http://localhost:7000/openapi/knowledge-bases/<kbId>/documents" \
  -H "Authorization: Bearer <token>" \
  -F "file=@test.txt"
```

也支持请求头：

```http
X-API-Token: <token>
```

## 常见问题

### 1. 登录后提示 401 或进入不了工作台

优先检查：

- Redis 是否启动
- Redis 密码是否正确
- 后端是否已经重启到最新代码

### 2. 文档上传失败

优先检查：

- `kbId` 是否存在
- 当前用户是否拥有该知识库
- `QWEN_API_KEY` 是否正确
- PostgreSQL 和 pgvector 是否可用

### 3. 历史对话不显示

优先检查：

- 后端是否是最新版本
- PostgreSQL 中 `conversations.user_id` 是否为空
- 登录态是否已经过期
