# AI-QA 架构升级设计方案

**版本**: v2.0.0
**日期**: 2026-03-17
**目标**: 企业级 RAG 知识库管理系统

---

## 一、当前问题分析

### 1.1 知识库未持久化

**现状**:
- 上传的文档仅存入向量数据库
- 没有知识库概念（如：员工手册库、财务制度库、产品知识库）
- 无法对知识库进行分类管理
- 无法控制 AI 可访问的知识库范围

**需求**:
```
用户 → 选择知识库 → AI 对话
      - 员工知识库
      - 财务知识库
      - 产品知识库
      - 自定义组合
```

### 1.2 前端展示不友好

**问题** (见截图 `docs/img.png`):
- Markdown 源码直接显示（`---`, `###`, `|` 等符号）
- 表格未正确渲染
- 列表格式混乱
- 非编程人员阅读困难

**原因**:
- marked.js CDN 可能加载失败
- 缺少 Markdown 渲染样式
- 没有代码高亮和格式化

### 1.3 缺少用户系统

**现状**:
- 无用户登录注册
- 无权限控制
- 无操作日志
- 无法追溯谁上传了什么文档

**需求**:
- 用户注册/登录
- 角色权限管理（管理员/普通用户）
- 操作审计日志

### 2.3 数据库表结构

```sql
-- 用户表
CREATE TABLE users (
    id UUID PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    password VARCHAR(255) NOT NULL,  -- BCrypt 加密
    email VARCHAR(100) UNIQUE,
    role VARCHAR(20) DEFAULT 'USER', -- ADMIN, USER
    avatar_url VARCHAR(255),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 知识库表
CREATE TABLE knowledge_bases (
    id UUID PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    description TEXT,
    cover_color VARCHAR(7) DEFAULT '#4F46E5',
    created_by UUID REFERENCES users(id),
    is_public BOOLEAN DEFAULT false,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 文档表
CREATE TABLE documents (
    id UUID PRIMARY KEY,
    kb_id UUID REFERENCES knowledge_bases(id) ON DELETE CASCADE,
    filename VARCHAR(255) NOT NULL,
    original_name VARCHAR(255),
    file_path VARCHAR(500),  -- MinIO 存储路径
    file_size BIGINT,
    file_type VARCHAR(50),   -- PDF, DOCX, TXT, MD
    chunk_count INTEGER,
    status VARCHAR(20),      -- PROCESSING, READY, FAILED
    uploaded_by UUID REFERENCES users(id),
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 用户知识库关联表（权限控制）
CREATE TABLE user_knowledge_bases (
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,
    kb_id UUID REFERENCES knowledge_bases(id) ON DELETE CASCADE,
    permission VARCHAR(20),  -- READ, WRITE, ADMIN
    created_at TIMESTAMP DEFAULT NOW(),
    PRIMARY KEY (user_id, kb_id)
);

-- 对话表（已有，增加 user_id）
CREATE TABLE conversations (
    id UUID PRIMARY KEY,
    user_id UUID REFERENCES users(id) ON DELETE CASCADE,  -- 新增
    title VARCHAR(255) NOT NULL,
    kb_ids TEXT,  -- 使用的知识库 ID 列表 (JSON 数组)
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 操作日志表
CREATE TABLE operation_logs (
    id UUID PRIMARY KEY,
    user_id UUID REFERENCES users(id),
    operation VARCHAR(50),     -- UPLOAD_DOC, DELETE_KB, LOGIN, etc.
    resource_type VARCHAR(50), -- DOCUMENT, KNOWLEDGE_BASE
    resource_id UUID,
    details JSONB,
    ip_address VARCHAR(50),
    created_at TIMESTAMP DEFAULT NOW()
);
```

```java
// 权限检查逻辑
public boolean canAccess(User user, UUID kbId, Permission permission) {
    // 1. 管理员直接通过
    if (user.getRole() == Role.ADMIN) return true;
    
    // 2. 检查知识库关联
    UserKB userKB = userKBRepository.findByUserIdAndKbId(user.getId(), kbId);
    if (userKB == null) return false;
    
    // 3. 检查权限等级
    return userKB.getPermission().level >= permission.level;
}
```

#### 使用场景
```java
// 1. JWT Token 缓存
@Value("${jwt.expiration:604800}")
private long tokenExpiration;

public void saveToken(String token, User user) {
    String key = "auth:token:" + token;
    redisTemplate.opsForValue().set(key, user.getId().toString(), tokenExpiration, TimeUnit.SECONDS);
}

// 2. 用户 Session 缓存
public void saveUserSession(UUID userId, String sessionId) {
    String key = "session:" + userId;
    redisTemplate.opsForValue().set(key, sessionId, 30, TimeUnit.MINUTES);
}

// 3. 热点数据缓存（知识库列表）
@Cacheable(value = "knowledgeBases", key = "#userId")
public List<KnowledgeBase> getUserKnowledgeBases(UUID userId) {
    return kbRepository.findByUserId(userId);
}

// 4. 接口限流
public boolean isRateLimited(String userId, String api, int limit) {
    String key = "ratelimit:" + userId + ":" + api + ":" + System.currentTimeMillis() / 60000;
    Long count = redisTemplate.opsForValue().increment(key);
    if (count == 1) {
        redisTemplate.expire(key, 60, TimeUnit.SECONDS);
    }
    return count > limit;
}
```

```java
@Service
public class MinioService {
    
    private final MinioClient minioClient;
    
    public String uploadFile(MultipartFile file, String bucket, String objectName) throws Exception {
        // 创建 bucket（如果不存在）
        if (!minioClient.bucketExists(BucketExistsArgs.builder().bucket(bucket).build())) {
            minioClient.makeBucket(MakeBucketArgs.builder().bucket(bucket).build());
        }
        
        // 上传文件
        minioClient.putObject(PutObjectArgs.builder()
                .bucket(bucket)
                .object(objectName)
                .stream(file.getInputStream(), file.getSize(), -1)
                .contentType(file.getContentType())
                .build());
        
        // 返回访问 URL
        return minioClient.getPresignedObjectUrl(GetPresignedObjectUrlArgs.builder()
                .bucket(bucket)
                .object(objectName)
                .method(Method.GET)
                .build());
    }
}
```

### 7.2 JWT 配置
```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws SecurityException {
        http
            .csrf(csrf -> csrf.disable())
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .sessionManagement(session -> session
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
            );
        return http.build();
    }
}
```

## 十、总结

### 当前问题解决方案

| 问题 | 解决方案 | 优先级 |
|------|----------|--------|
| 知识库未持久化 | 新增知识库表，支持多知识库管理 | P0 |

### 技术选型

| 组件 | 技术 | 说明 |
|------|------|------|
| 认证 | Spring Security + JWT | 标准方案 |
| 缓存 | Redis | Session/限流/热点数据 |
| 文件存储 | MinIO | 分布式对象存储 |
| 数据库 | PostgreSQL + pgvector | 向量 + 关系型 |
| 前端 | Thymeleaf → Vue 3 | 渐进式升级 |

### 预期成果

1. **完整的知识库管理** - 支持多知识库、权限控制
2. **友好的前端展示** - Markdown 正确渲染
3. **企业级用户系统** - 登录注册、权限管理、操作审计
4. **可扩展架构** - 支持水平扩展、高可用
