# RAG 验证测试指南

## 一、快速验证（5 分钟）

### 1. 启动服务
```cmd
# 设置环境变量
set QWEN_API_KEY=你的 API 密钥

# 启动应用
mvn spring-boot:run
```

### 2. 上传测试文档
1. 访问 http://localhost:7000/rag
2. 上传 `docs/测试文档/员工手册.md`
3. 等待处理完成，查看返回的切片统计

**预期输出**:
```
文档上传并处理成功，共生成 X 个片段 (平均每个片段 XXX 字符，重叠率 XX%)
```

### 3. 测试 RAG 对话
1. 访问 http://localhost:7000
2. **打开 RAG 知识库开关**
3. 提问测试问题（见下方测试题库）

## 三、验证 RAG 是否生效

### 方法 1: 对比测试

**步骤**:
1. **关闭 RAG 开关**，提问："公司年假有多少天？"
   - 预期：AI 回答不知道或通用答案
   
2. **打开 RAG 开关**，提问同样问题
   - 预期：AI 回答"工作满 1 年后享受 5 天带薪年假"

### 方法 2: 查看日志

**启动应用后查看日志**:
```
收到 RAG 对话请求，问题：公司年假有多少天？
检索到 5 个相关文档片段
片段 1: filename=员工手册.md, content=年假：工作满 1 年后享受 5 天带薪年假...
开始 Rerank 重排序...
Rerank 重排序完成，返回 Top-3 文档
Top-1 评分：0.9234, 内容：年假：工作满 1 年后享受 5 天带薪年假
```

**关键日志**:
- `检索到 X 个相关文档片段` - 向量检索成功
- `Rerank 重排序完成` - 重排序成功
- `Top-1 评分：0.xxxx` - 相关性评分

### 方法 3: 检查数据库

```sql
-- 查看向量库中文档
SELECT metadata->>'filename' as filename, 
       count(*) as chunks
FROM vector_store_1024 
GROUP BY metadata->>'filename';

-- 查看对话历史
SELECT * FROM conversations 
ORDER BY updated_at DESC 
LIMIT 5;
```

## 五、常见问题排查

### Q1: 文档上传失败
**检查**:
- 文件格式是否支持（.md/.txt/.pdf/.docx）
- 文件大小是否超过限制
- 查看后端日志错误信息

### Q2: RAG 回答不准确
**优化**:
- 调整相似度阈值：`spring.ai.vectorstore.pgvector.similarity-threshold=0.5`
- 调整切片大小：`ai.service.document.splitter.default-chunk-size=256`
- 补充相关文档到知识库

### Q3: 响应时间过长
**排查**:
- 检查数据库连接
- 查看 Rerank API 调用耗时
- 降低 top-n 值：`ai.service.rerank.top-n=2`
