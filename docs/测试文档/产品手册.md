# AI-QA 产品使用手册

## 产品简介

AI-QA 是一款基于人工智能的智能问答系统，可帮助企业快速搭建知识库客服系统。

### 核心功能
- 智能对话：支持多轮对话，理解上下文
- 知识库检索：基于 RAG 技术，准确回答专业问题
- 文档管理：支持 PDF、Word、TXT 等多种格式
- 对话历史：完整保存对话记录，支持追溯

## 快速开始

### 第一步：上传知识库文档
1. 访问 http://localhost:7000/rag
2. 点击"选择文件"按钮
3. 选择要上传的文档（支持 PDF、Word、TXT）
4. 等待文档处理完成

### 第二步：开始对话
1. 访问 http://localhost:7000
2. 在输入框中输入问题
3. 点击发送或按回车键
4. AI 会实时返回答案

### 第三步：切换 RAG 模式
1. 在对话页面找到"RAG 知识库"开关
2. 打开开关启用知识库增强
3. 提问时 AI 会优先基于知识库回答

## 常见问题

### Q1: 上传文档失败怎么办？
- 检查文件格式是否支持（PDF/Word/TXT）
- 确保文件大小不超过 10MB
- 查看浏览器控制台错误信息

### Q2: AI 回答不准确如何优化？
- 在知识库中补充相关文档
- 调整切片参数（默认 512 token）
- 调整相似度阈值（默认 0.6）

### Q3: 如何查看对话历史？
- 在对话页面左侧点击对话列表
- 点击任意历史对话查看详情
- 支持删除和重命名对话

## 技术规格

### 系统要求
- Java 17+
- PostgreSQL 16+ (带 pgvector 扩展)
- Maven 3.6+

### 性能指标
- 响应时间：< 2 秒（普通对话）
- 响应时间：< 3 秒（RAG 对话）
- 并发支持：100+ 用户

### 安全特性
- API 密钥加密存储
- 对话数据隔离
- 支持私有化部署
