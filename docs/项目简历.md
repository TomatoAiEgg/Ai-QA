# AI-QA 项目简历

## 项目名称

AI-QA 智能知识库问答平台

## 项目描述

AI-QA 是一个面向企业私有知识库问答场景的全栈 RAG 平台，支持多知识库管理、文档异步处理、向量检索增强问答、OpenAPI 文档接入和 Docker Compose 云服务器部署。项目后端基于 Spring Boot、Spring AI、MyBatis-Plus，前端基于 Vue 3，底层使用 PostgreSQL + pgvector 承载向量检索，结合 Redis、RocketMQ、MinIO 完成缓存、异步处理和对象存储。

## 核心亮点

- 设计并实现完整 RAG 链路：文档解析、切片、Embedding、向量入库、相似度检索、上下文组装和大模型流式回答，支持按知识库隔离检索和全局检索。
- 使用 RocketMQ 解耦文档上传和向量化处理，文档处理链路支持状态流转、失败重试、幂等保护和批量向量写入，避免上传接口被大文件解析阻塞。
- 抽象文档存储层，默认接入 MinIO 保存原文件，并通过签名地址实现安全预览，避免文件直接暴露在应用静态目录下。
- 基于 Redis 实现登录态缓存、验证码一次性消费和业务查询缓存；认证体系收口为邮箱登录/注册，并增加图形验证码防止接口被刷。
- 对 OpenAPI token 做摘要存储，外部系统可通过 token 上传文档到指定知识库，同时避免明文 token 落库。
- 对聊天模型调用增加模型池自动切换和网络异常重试，降低单模型额度耗尽或瞬时网络错误对业务的影响。
- 对聊天 Markdown 渲染、全局异常返回、Redis 序列化配置进行安全收敛，减少 XSS、反序列化和内部错误泄漏风险。
- 使用 Docker Compose 编排 PostgreSQL、Redis、MinIO、RocketMQ、后端和 Nginx，统一数据目录和日志目录，支持服务器拉取代码后一条命令完成构建部署。

## 技术栈

Spring Boot 3.4.2、Spring AI、MyBatis-Plus、Sa-Token、PostgreSQL、pgvector、Redis、RocketMQ、MinIO、DashScope/Qwen、Vue 3、Vite、Element Plus、Nginx、Docker Compose
