# AI-QA 项目简历

## 项目名称

AI-QA 智能知识库问答平台

## 项目描述

AI-QA 是一个面向企业知识问答与智能客服场景的全栈项目，支持大模型对话、RAG 检索增强问答、知识库管理、历史会话管理、用户鉴权与开放接口接入。项目采用前后端分离架构，后端基于 Spring Boot 与 Spring AI，前端基于 Vue 3 与 Element Plus，底层结合 PostgreSQL、pgvector 与 Redis 实现向量检索、数据持久化与缓存加速。

## 功能介绍

- 支持普通 AI 对话与流式输出
- 支持基于知识库的 RAG 对话
- 支持多知识库创建、编辑、删除与文档管理
- 支持文档上传、切片预览、向量化入库与文档预览
- 支持邮箱或手机号注册登录
- 支持历史对话列表、消息记录与标题维护
- 支持 Redis 登录态缓存与业务查询缓存
- 支持对外开放知识库文档上传接口，允许外部系统通过 token 将文件写入指定知识库

## 项目亮点

- 基于 Spring AI + pgvector 实现完整 RAG 链路，覆盖文档切片、向量入库、相似度检索和问答整合
- 使用 MyBatis-Plus 替换原始 JDBC，统一实体、Mapper 与服务层数据访问方式
- 接入 Sa-Token 完成用户鉴权，并结合 Redis 存储登录态与查询缓存，降低数据库读取压力
- 支持多用户隔离的知识库、文档和历史会话管理，保证数据按用户维度归属
- 设计并实现开放接口能力，支持外部项目通过 token 上传文档到指定知识库
- 前端支持流式 Markdown 实时渲染、知识库工作台管理和主题切换，提升实际可用性

## 技术栈

Spring Boot 3.4.2、Spring AI 1.0.0-M5、MyBatis-Plus、Sa-Token、PostgreSQL、pgvector、Redis、Vue 3、Vite、Element Plus

## 掌握技能

掌握 Spring Boot 后端开发、RESTful API 设计、MyBatis-Plus 数据访问、Sa-Token 用户鉴权、Redis 缓存与登录态管理、PostgreSQL 与 pgvector 向量检索、Spring AI 大模型与 RAG 知识库问答集成、Vue 3 前后端分离项目开发、流式 SSE 响应处理、文件上传与文档切片处理、多用户数据隔离与开放接口设计。
