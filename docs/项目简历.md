# AI-QA 项目简历

## 项目名称

AI-QA 智能知识库问答平台

## 项目描述

AI-QA 是一个面向企业知识问答、内部资料检索和智能客服场景的全栈知识库问答平台。项目采用前后端分离架构，后端基于 Spring Boot、Spring AI 和 MyBatis-Plus，前端基于 Vue 3、Vite 和 Element Plus，结合 PostgreSQL、pgvector、Redis、RocketMQ 与 MinIO 实现用户认证、知识库管理、RAG 检索增强问答、异步文档处理、对象存储、开放接口接入和 Docker Compose 一键部署。

项目支持普通 AI 对话和基于知识库的 RAG 对话，用户可以创建多个知识库并上传文档，系统将文档写入对象存储后通过 RocketMQ 异步消费，完成文档读取、切片、批量向量化和向量入库。平台同时提供邮箱注册登录、登录/注册验证码、昵称修改、历史会话管理、OpenAPI token 上传文档等能力，适合作为企业私有知识库问答系统的完整实践项目。

## 功能介绍

- 支持普通 AI 对话、流式 SSE 输出和 Markdown 内容渲染。
- 支持 RAG 检索增强问答，可按指定知识库或全部知识库进行上下文检索。
- 支持多知识库创建、编辑、删除和用户维度数据隔离。
- 支持文档上传、状态轮询、失败重试、删除和原文件预览。
- 支持 RocketMQ 异步文档处理，上传链路和向量化处理链路解耦。
- 支持 MinIO 对象存储，文档原文件默认写入对象存储并通过签名地址预览。
- 支持 PostgreSQL + pgvector 向量存储，文档切片后批量向量化并批量写入向量库。
- 支持邮箱注册、邮箱登录、注册邮箱占用检查和 Redis 验证码防刷。
- 支持工作台昵称修改，修改成功后同步刷新当前登录态。
- 支持历史对话列表、消息记录持久化、会话标题维护和多轮上下文管理。
- 支持 Redis 登录态缓存、业务查询缓存和验证码一次性消费。
- 支持 OpenAPI token 管理，外部系统可通过 token 上传文档到指定知识库。
- 支持聊天模型池自动切换和网络异常重试，提高大模型调用稳定性。
- 支持 Docker Compose 一键部署 PostgreSQL、Redis、MinIO、RocketMQ、后端、Nginx 和可选 Portainer。

## 项目亮点

- 基于 Spring AI + pgvector 实现完整 RAG 链路，覆盖文档切片、Embedding、向量入库、相似度检索、上下文组装和大模型回答。
- 使用 RocketMQ 将文档上传和文档解析向量化解耦，文档处理支持状态流转、失败重试和幂等保护，避免重复消费导致脏写。
- 抽象文档存储层，支持本地存储和 MinIO 对象存储切换，默认使用 MinIO 保存原文件并提供签名预览能力。
- 使用 Sa-Token + Redis 实现登录态管理，认证体系收口为邮箱登录/注册，并通过 Redis 图形验证码降低接口被刷风险。
- 对 OpenAPI token 进行摘要存储，避免明文 token 落库，并对全局异常返回做安全收敛，减少内部错误泄漏。
- 使用 MyBatis-Plus 统一实体、Mapper 与服务层数据访问，按业务域拆分 `auth`、`chat`、`document`、`knowledgebase`、`openapi` 等模块。
- 前端实现工作台式知识库管理、文档状态轮询、原文件预览、昵称弹框修改、邮箱验证码登录注册和移动端适配。
- Docker Compose 统一编排后端、前端、中间件和日志/数据挂载目录，支持服务器拉取代码后直接构建部署。

## 技术栈

Spring Boot 3.4.2、Spring AI 1.0.0-M5、MyBatis-Plus、Sa-Token、PostgreSQL、pgvector、Redis、RocketMQ、MinIO、DashScope/Qwen 兼容 OpenAI 接口、Vue 3、Vite、Element Plus、Nginx、Docker Compose

## 掌握技能

掌握 Spring Boot 后端开发、RESTful API 设计、MyBatis-Plus 数据访问、Sa-Token 用户鉴权、Redis 登录态/缓存/验证码管理、PostgreSQL 与 pgvector 向量检索、Spring AI 大模型接入、RAG 知识库问答链路设计、RocketMQ 异步消息消费、MinIO 对象存储、OpenAPI token 鉴权、Vue 3 前后端分离开发、SSE 流式响应处理、Markdown 渲染安全处理、文件上传与文档处理、Docker Compose 云服务器部署、多用户数据隔离和接口安全加固。
