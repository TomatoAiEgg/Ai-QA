## 最近更新

### v2.5.2

- RAG 向量存储切换到新版向量表 `vector_store_1024_v2`，核心字段拆分为 `user_id`、`kb_id`、`doc_id`、`chunk_index`
- 后端上传文档时改为手动生成 embedding 并写入新表，检索逻辑改为直接查询新表
- 删除旧的 `spring.ai.vectorstore.pgvector.*` 自动落表配置，不再依赖旧表 `vector_store_1024`
- 聊天页知识库下拉新增显式默认值“全部知识库”，未选择具体知识库时按全库检索
- 修复知识库管理页创建知识库后聊天页下拉不回显的问题，新增前端知识库刷新通知
- 新增 `database/vector_store_1024_v2.sql`，用于手工创建新版向量表
- 新增 `docs/云服务器部署指南.md`，补充单机 Docker 部署、Nginx 反向代理、目录规划与 K8s 试玩说明
- 新增 `logback-spring.xml`，日志支持输出到文件并按天滚动归档
- 补充关键业务日志，覆盖登录、会话恢复、知识库增删改、文档上传/删除、RAG 命中数量和 OpenAPI 上传链路

### v2.5.1

- 登录页新增输入框级表单校验，账号框在失焦时直接提示邮箱或手机号格式错误
- 前端登录页在切换邮箱/手机号模式时会同步刷新账号输入框校验状态
- 后端登录接口新增账号格式校验，非法邮箱或手机号不会继续进入查库逻辑
- 关闭 Spring 启动时自动执行 `schema.sql`，应用不再自动修改现有数据库结构
- 删除项目内置 `schema.sql`，改为手工导入数据库
- 新增 `database/` 目录，导出当前 PostgreSQL 的结构脚本 `susan_ai_schema.sql`
- 新增 `database/` 目录，导出当前业务数据脚本 `susan_ai_data.sql`
- 新增 `database/README.md`，说明数据库导入顺序和注意事项

### v2.5.0

- 新增开放接口令牌能力，支持为登录用户创建、查看、废弃 OpenAPI token
- 新增 `/openapi/knowledge-bases/{kbId}/documents`，外部系统可通过 token 将文件上传到指定知识库
- 重构 Sa-Token 拦截逻辑，SSE 异步响应不再因二次鉴权触发 `SaTokenContext` 异常
- 修复 `/api/auth/session` 会话恢复链路，读取 Redis 坏缓存时会自动清理并回源数据库
- 修复登录态缓存对象构建方式，改用稳定的 `LinkedHashMap`，解决刷新页面反复出现 Redis 反序列化异常的问题
- 登录态过期时间调整为 7 天，前端本地会话增加过期校验
- 前端登录页重做为账号中心风格，关闭注册入口，仅保留已有账号登录
- 更新 `docs/入门指南.md`，删除旧的架构设计与 RAG 增量文档，新增 `docs/项目简历.md`

### v2.4.0

- 接入 Redis，新增 `spring-boot-starter-data-redis`、`spring-boot-starter-cache` 和 `sa-token-redis-jackson`
- Sa-Token token 与会话信息改存 Redis，登录后按 token 缓存用户登录态
- 前端新增本地登录态持久化，浏览器保存当前用户信息和 token，并在请求时自动携带
- 会话列表、会话消息、知识库列表、知识库详情、文档列表、文档预览接入 Redis 读缓存
- PostgreSQL 继续承担主数据写入和更新，查询请求优先通过 Redis 缓存返回
- `knowledge_base_documents` 新增 `user_id`，文档直接归属用户
- 上传文档时写入 `user_id` 和向量元数据，文件按用户目录落盘
- 查询、删除、预览文档统一按 `user_id` 做隔离
- 修复工作台初始化时 `/api/auth/session` 未登录错误被错误包装的问题，恢复为标准 `401`
- `docker-compose.yml` 补充 Redis 服务，方便本地一键启动

### v2.3.0

- 解决进入页面不加载历史对话、点击历史对话无响应的问题

- 补齐文档删除接口和文档预览接口
- RAG 检索按 `kbId` 过滤，删除文档或知识库时同步清理向量数据
- 修复 SSE 多行 `data:` 解析，流式输出时保留 Markdown 换行
- 修复流式 Markdown 渲染，AI 回复过程中即可展示样式，无需刷新

## 运行要求

后端：

- Java 17
- PostgreSQL
- Redis
- `QWEN_API_KEY` 环境变量

前端：

- Node.js
- `npm install`
- `npm run dev`

后端启动示例：

```powershell
$env:JAVA_HOME='D:\Javasource\jdk-17.0.9'
$env:PATH="$env:JAVA_HOME\bin;D:\Javasource\apache-maven-3.9.2\bin;$env:PATH"
mvn spring-boot:run
```

## 说明

- 会话、知识库和文档数据目前统一走 MyBatis-Plus
- 数据库初始化改为手工导入 `database/` 目录中的 SQL 文件，不再依赖应用启动自动建表
- 登录态和读缓存走 Redis，PostgreSQL 作为主数据源负责写入和更新
- 文档预览依赖上传后保存的原文件；旧数据如果没有 `storage_path`，可能无法直接预览
