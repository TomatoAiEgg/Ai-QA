## v2.1.0 (2026-03-21) - 前端重构

### 核心变更

| 变更项 | 内容 |
|--------|------|
| 前端重命名 | `susan-ai-ui` → `Ai-QA-ui` |
| 路由简化 | 删除 `/rag` 路由，改为模态框 |
| 交互优化 | 点击"新对话"清空当前对话，点击预文本自动创建对话 |

### 主要改动

**1. RAG 改为模态框**
- 删除 `/rag` 路由，RagView 改为模态框组件
- 点击知识库按钮弹出模态框，关闭后保持对话状态

**2. 对话逻辑优化**
```javascript
// 页面加载时自动选中第一个历史对话
loadAndSelectFirstConversation()
  → 有历史：选中第一个并加载消息
  → 无历史：显示欢迎页

// 点击预文本
useSuggestion(text)
  → 创建新对话 → 发送消息
```

**3. 组件通信**
- 使用 `provide/inject` 传递方法
- 使用 `CustomEvent` 实现组件解耦

### 文件变更
- `App.vue` - 引入 RagView 模态框、优化对话管理
- `RagView.vue` - 改为模态框组件
- `ChatView.vue` - 优化预文本逻辑
- `router/index.js` - 删除 /rag 路由

## v2.0.0 (2026-03-18) - 多知识库管理

### 核心变更

| 变更项 | 内容 |
|--------|------|
| 新增表 | `knowledge_bases` (知识库表) |
| 新增表 | `knowledge_base_documents` (文档关联表) |
| RAG 增强 | 支持按知识库 ID 过滤检索 |

### 数据库表结构

**knowledge_bases**: 存储知识库元信息（名称、描述、封面颜色）

**knowledge_base_documents**: 存储文档上传记录（文件名、状态、切片数）

### 新增 API

| 接口 | 说明 |
|------|------|
| `/api/knowledge-bases` | 创建/获取知识库 |
| `/api/knowledge-bases/{id}/documents` | 获取知识库文档列表 |
| `/ai/upload?kbId=xxx` | 上传文档到指定知识库 |
| `/ai/chatByRag?kbId=xxx` | 按知识库 RAG 检索 |

## v1.1.0 (2026-03-17) - Rerank 重排序

### 核心变更

| 变更项 | 内容 |
|--------|------|
| 项目更名 | `susan-ai` → `AI-QA` |
| 新增服务 | `RerankService` 重排序服务 |
| Embedding 模型 | `text-embedding-v3` (1024 维) |
| Rerank 模型 | `qwen3-rerank` |

### RAG 流程变更

```
用户提问 → 向量检索 → Rerank 重排序 → 构建 Prompt → 千问 API
                        ↑
                   新增步骤（提升准确率 10-30%）
```

### 配置
```properties
ai.service.rerank.enabled=true
ai.service.rerank.min-score=0.5
ai.service.rerank.top-n=3
```

## v1.0.0 (2026-03-13) - 迁移千问模型

### 变更
- 从 Ollama 迁移至阿里千问（DashScope）

```properties
spring.ai.openai.chat.options.model=qwen3-max
```

## 技术架构

### RAG 完整流程

```
用户提问
   ↓
保存用户问题到数据库
   ↓
向量检索 (text-embedding-v3, 1024 维)
   ↓
Rerank 重排序 (qwen3-rerank, Top-3)
   ↓
构建 Prompt (系统提示 + 历史对话 + 上下文)
   ↓
千问 API 流式响应
   ↓
保存完整回复到数据库
```

## 配置项总览

```properties
# 基础配置
spring.application.name=AI-QA
server.port=7000

# 千问模型
spring.ai.openai.api-key=${QWEN_API_KEY}
spring.ai.openai.chat.options.model=qwen3-max
spring.ai.openai.embedding.options.model=text-embedding-v3

# 向量数据库
spring.ai.vectorstore.pgvector.table-name=vector_store_1024
spring.ai.vectorstore.pgvector.dimension=1024

# 文档切片器
ai.service.document.splitter.default-chunk-size=512

# Rerank
ai.service.rerank.enabled=true
ai.service.rerank.min-score=0.5
ai.service.rerank.top-n=3
```

## API 接口一览

| 接口 | 方法 | 说明 |
|------|------|------|
| `/ai/chat` | POST | AI 对话（流式） |
| `/ai/chatByRag` | POST | RAG 知识库对话（流式） |

| `/ai/conversations/{id}/title` | PUT | 修改对话标题 |
| `/ai/conversations/{id}/messages` | GET | 获取对话消息 |

## 注意事项

1. **API 密钥**: 通过环境变量 `QWEN_API_KEY` 设置
2. **向量维度**: text-embedding-v3 使用 1024 维
3. **Rerank 延迟**: 每次 RAG 对话增加约 200-500ms
4. **免费额度**: Embedding 和 Rerank 各有 50-100 万/月免费调用
