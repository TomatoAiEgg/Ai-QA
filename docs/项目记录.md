## 当前推荐部署方式

从 GitHub 拉取后直接在服务器执行：

```bash
cd /opt/projects
git clone https://github.com/TomatoAiEgg/Ai-QA.git ai-qa
cd /opt/projects/ai-qa
cp .env.example .env
vim .env
docker compose up -d --build
```

其中 `.env` 只保留在服务器本地，至少需要填写：

```env
QWEN_API_KEY=你的真实千问秘钥
```

## 说明

- 数据库初始化依赖 `database/` 目录下的 SQL 文件
- PostgreSQL 使用 `pgvector/pgvector:pg17-trixie`
- Redis 使用 `redis:7.4`
- 日志目录固定为 `/opt/logs/ai-qa`
- 上传文件目录固定为 `/opt/data/ai-qa/kb-files`
