### 2. 新增 Rerank 重排序功能

#### 为什么需要 Rerank？

| 检索方式 | 优势 | 劣势 |
|----------|------|------|
| **向量检索** | 语义匹配好 | 关键词匹配弱，可能漏掉相关内容 |
| **Rerank** | 精确判断相关性 | 增加 200-500ms 延迟 |
| **向量+Rerank** | 两者兼顾 | 最佳实践 |

**预期提升**: 检索准确率提升 10-30%

#### 2.1 新增 RerankService

**文件**: `src/main/java/cn/net/susan/ai/service/RerankService.java`

**功能**:
- 使用阿里百炼 Rerank API 对向量检索结果进行重排序
- 支持配置最低分数阈值和返回数量
- 失败时自动降级返回原始结果

**工作流程**:
```
用户提问
   ↓
向量检索 (Top-5)  ← pgvector 相似度搜索
   ↓
Rerank 重排序      ← 阿里百炼 qwen3-rerank
   ↓
过滤 + 排序        ← 过滤 < 0.5 分，降序排列
   ↓
返回 Top-3         ← 最相关文档
   ↓
构建 Prompt → 千问 API → 返回答案
```

**核心代码**:
```java
@Service
public class RerankService {
    
    public List<Document> rerank(String query, List<Document> documents) {
        // 1. 提取文档内容
        List<String> contents = documents.stream()

        Request request = new Request.Builder()

                .build();

        // 4. 过滤低分文档，按评分降序排序
        // 5. 返回 Top-N 文档
    }
}
```

#### 2.2 修改 AiService 集成 Rerank

**文件**: `src/main/java/cn/net/susan/ai/service/AiService.java`

**变更**:
- 注入 `RerankService`
- 在 RAG 流程中增加 Rerank 步骤（步骤 4.5）

**集成位置**:
```java
public Flux<String> chatByRag(String question, UUID conversationId, String model) {
    // 步骤 1-3: 向量检索
    List<Document> documents = vectorStore.similaritySearch(...);
    
    // 步骤 4.5: Rerank 重排序（新增）
    if (rerankService.isEnabled()) {
        documents = rerankService.rerank(question, documents);
    }
    
    // 步骤 5-10: 构建 Prompt，调用千问 API
}
```

#### 2.3 配置项

**application.properties**:
```properties
# Rerank 配置
ai.service.rerank.enabled=true
ai.service.rerank.model=qwen3-rerank
ai.service.rerank.min-score=0.5    # 最低相关性分数
ai.service.rerank.top-n=3          # 返回 Top-3 文档
```

**参数说明**:
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `enabled` | true | 是否启用 Rerank |
| `model` | qwen3-rerank | Rerank 模型名称 |
| `min-score` | 0.5 | 最低分数阈值（0-1） |
| `top-n` | 3 | 返回最相关的文档数 |

**调整建议**:
```properties

ai.service.rerank.top-n=2

# 更宽松（返回更多文档）
ai.service.rerank.min-score=0.3

```

### 1. 新增 DocumentSplitterConfiguration

**文件**: `src/main/java/cn/net/susan/ai/config/DocumentSplitterConfiguration.java`

**配置参数**（可通过 `application.properties` 调整）:

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `defaultChunkSize` | 512 | 每个文档块的目标大小（token 数） |
| `minChunkSizeChars` | 128 | 每个文档块的最小字符数 |
| `minChunkLengthToEmbed` | 5 | 被嵌入的块的最小长度 |
| `maxNumChunks` | 10000 | 单个文档生成的最大片段数 |
| `keepSeparator` | true | 是否保留分隔符（如换行符） |

**配置示例**:

## 技术说明

### Rerank 重排序详解

#### API 调用
```http
POST https://dashscope.aliyuncs.com/api/v1/services/rerank/text-generation/rerank
Authorization: Bearer ${QWEN_API_KEY}
Content-Type: application/json

{
  "model": "qwen3-rerank",
  "input": {
    "query": "如何请假？",
    "documents": [
      {"text": "员工请假流程..."},
      {"text": "病假需要提供医院证明..."}
    ]
  },
  "parameters": {
    "top_n": 3
  }
}
```

#### 响应格式
```json
{
  "output": {
    "results": [
      {"index": 0, "relevance_score": 0.92},
      {"index": 1, "relevance_score": 0.85}
    ]
  }
}
```

### SSE 流式响应格式
```
data: 你
data: 好
data: ，
```

### 重叠率计算
```
重叠率 = (总切片字符数 / 原始字符数 - 1) × 100%
```
- 重叠率越高：上下文保留越好，向量存储成本越高

### TokenTextSplitter 工作原理
1. **文本分块**: 按 token 数切分长文档
2. **重叠处理**: 相邻块保留重叠内容
3. **分隔符保留**: 可选择保留换行符等格式
