# AI-QA 项目记录

## 最近更新

### v2.3.0
- 数据访问层从原始 JDBC 仓库切换到 MyBatis-Plus，新增实体、Mapper 和统一建表脚本 [schema.sql](/D:/workspace/包装项目/Ai-QA/src/main/resources/schema.sql)
- 补齐 PostgreSQL `UUID` 映射，修复历史对话和知识库列表接口返回 `id = null`，解决“进入页面不加载历史对话、点击历史对话无反应”
- 对齐前后端接口参数，聊天请求统一支持 `model`、`useRag`、`kbId`
- 修复会话标题更新接口，兼容前端 JSON body 调用
- 补齐文档删除接口和文档预览接口，上传文档后可重新切片预览
- RAG 检索按 `kbId` 过滤，删除文档或知识库时同步清理向量数据
- 知识库及文档表改为自动建表，新环境不再依赖手工初始化
- 修复 SSE 多行 `data:` 解析，流式输出时保留 Markdown 换行
- 修复流式 Markdown 渲染，AI 回复过程中即可展示样式，无需刷新
- 重做前端工作台布局，新增主题切换
- 重做知识库管理界面，支持直接点击知识库卡片进入详情
- 支持编辑知识库名称和描述
- 优化文档列表展示
- 修复知识库文档数量首次进入不显示的问题

## 当前状态

当前主线功能包括：
- 普通 AI 对话
- RAG 对话
- 多知识库管理
- 历史会话管理
- 文档上传、预览、删除
- 流式 Markdown 展示
- 主题切换和知识库工作台 UI

## 运行要求

后端：
- Java 17
- PostgreSQL
- `QWEN_API_KEY` 环境变量

前端：
- Node.js
- `npm install`
- `npm run dev`

后端启动示例：

```powershell
$env:JAVA_HOME='D:\Javasource\jdk-17.0.9'
$env:PATH="$env:JAVA_HOME\bin;D:\Javasource\apache-maven-3.9.2\bin;$env:PATH"
mvn spring-boot:run
```

## 说明

- 会话、知识库和文档数据目前统一走 MyBatis-Plus
- 表结构初始化由 [schema.sql](/D:/workspace/包装项目/Ai-QA/src/main/resources/schema.sql) 负责
- 文档预览依赖上传后保存的原文件；旧数据如果没有 `storage_path`，可能无法直接预览
