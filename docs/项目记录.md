## 最近变更

### v2.2.0 - 前后端联调修复

本次更新聚焦业务可用性，而不是界面重构。

- 统一聊天接口参数，前端会真实传递 `model`、`kbId`、`useRag`
- 修复会话标题修改接口，后端兼容 JSON body
- 补齐文档删除接口 `/ai/documents/{id}`
- RAG 检索支持按知识库 `kbId` 过滤，不再是“前端传了但后端没用”
- 上传文档时补充 `doc_id`、`kb_id` 元数据，删除文档/知识库时同步清理向量库
- 知识库相关表支持自动建表，新环境可直接启动
- 聊天页新增知识库选择，RAG 对话可指定知识库
- 修复推荐问题失败后页面卡在“正在回复”的状态
- 修复 SSE 流式解析，保留多行 `data:` 内容中的换行
- 修复流式 Markdown 展示，AI 输出时即可逐步按样式渲染，无需刷新页面

涉及文件：

- `src/main/java/cn/net/tomatoegg/ai/controller/AiController.java`
- `src/main/java/cn/net/tomatoegg/ai/service/KnowledgeBaseService.java`
- `src/main/java/cn/net/tomatoegg/ai/service/KnowledgeBaseManagementService.java`
- `src/main/java/cn/net/tomatoegg/ai/repository/KnowledgeBaseRepository.java`
- `src/main/java/cn/net/tomatoegg/ai/repository/KnowledgeBaseDocumentRepository.java`
- `ui/src/api.js`
- `ui/src/views/ChatView.vue`

## 运行说明

后端要求：

- Java 17
- PostgreSQL
- `QWEN_API_KEY` 环境变量

前端要求：

- Node.js
- `npm install`
- `npm run dev`

后端常用启动方式：

```powershell
$env:JAVA_HOME='D:\Javasource\jdk-17.0.9'
$env:PATH="$env:JAVA_HOME\bin;D:\Javasource\apache-maven-3.9.2\bin;$env:PATH"
mvn spring-boot:run
```
